# My-Personal-Blog

## Description

Module 4 Challenge

A web application for a Personal Blog to keep track of all your thoughts, ideas and stories! 

Motivation for development:  
Have you ever had an idea that you just needed to remember? Well now you can keep track of everything thats inside your head with your very own Personal Blog.

User Story
AS A marketing student
I WANT a personal blog
SO THAT I can showcase my thoughts and experiences
